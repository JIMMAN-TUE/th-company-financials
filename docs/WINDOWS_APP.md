# thfin สำหรับ Windows

แอปเลือกขอบเขตบริษัทแล้วรวบรวม/นำเข้างบการเงิน เปิดหน้าจอใน browser ของเครื่อง
ZIP รวม Python, แพ็กเกจ thfin และ Chromium แล้ว ผู้ใช้ไม่ต้องติดตั้ง Python
รองรับ Windows x64; build และทดสอบบน Windows runner ของ GitHub Actions

## เปิดใช้และส่งต่อ

1. ดาวน์โหลด `thfin-windows.zip` จาก artifact `thfin-windows` ของ workflow **Windows app** ใน PR นี้
   artifact บน GitHub เก็บไว้ 30 วันและต้องมีสิทธิ์เข้าถึง repo; ดาวน์โหลด ZIP มาเก็บหรือส่งให้ทีมได้
2. แตก ZIP ทั้งหมดก่อน ให้เก็บ `thfin.exe` และโฟลเดอร์ `_internal` ไว้ด้วยกันในโฟลเดอร์แอป
3. ดับเบิลคลิก `thfin.exe` แอปจะเปิดหน้า UI ใน browser และมีหน้าต่าง console คุมโปรแกรม
   เปิด console ทิ้งไว้ระหว่างใช้ ปิดด้วย Ctrl+C หลังหยุดงานแล้ว
4. โฟลเดอร์ข้อมูลเริ่มต้นอยู่ที่ `%LOCALAPPDATA%\thfin` แต่ละคนใช้ข้อมูลของตนเอง
   ZIP ติดตั้งไม่รวมทะเบียน งบ ฐานข้อมูล อีเมลติดต่อ หรือข้อมูลจริงจากผู้สร้าง

## ใช้ตาม scope widget

1. นำเข้า CSV ทะเบียนบริษัทผ่านช่อง **เตรียมข้อมูล** แล้วเลือกปี จังหวัด หมวด TSIC และตัวกรอง
   ดูจำนวนตรงเงื่อนไข จำนวนที่เลือก และเวลาโดยประมาณก่อนรัน เพดานบริษัทไม่ถูกเพิ่มเอง
2. เปิด **ตั้งค่าแหล่งข้อมูล** ใส่ข้อมูลติดต่อและตรวจ URL หน้าบริษัท ซึ่งต้องมี `{juristic_id}`
   URL เริ่มต้นยังเป็น placeholder และยังไม่ยืนยันการเข้า DataWarehouse+ จริง
3. กำหนดจำนวนบริษัทต่อรอบแล้วกด **เริ่มดึงข้อมูลงบ** งานใช้ scope ณ ตอนกดเริ่ม
   ถ้าเปลี่ยน widget ระหว่างรัน งานเดิมยังใช้ขอบเขตเดิม รายละเอียดแสดงใต้สถานะ
   กด **หยุด** เพื่อหยุดหลังคำขอปัจจุบัน จากนั้นเริ่มใหม่เพื่อทำต่อจากข้อมูลที่บันทึกแล้ว
   หลังแก้ URL วิธีอ่านหน้าเว็บ หรือหน่วยงบ ให้เลือก **ประมวลผลใหม่** ก่อนกดเริ่ม เพื่ออัปเดตบริษัทที่เคยเก็บแล้ว
   ตัวเลือกนี้เริ่มจากบริษัทแรกใน scope ตามจำนวนต่อรอบ หากต้องการแก้ทั้ง scope ให้ตั้งจำนวนต่อรอบให้ครอบคลุมหรือแบ่ง scope
4. กด **ดูผลลัพธ์** หรือดาวน์โหลด Excel/CSV ผลถูกกรองทั้งบริษัท ปีงบ และช่วงรายได้
   ตารางแสดง 100 แถวแรก ไฟล์ export มีผลทั้งหมดใน scope ปัจจุบัน

ถ้าเลือกใช้ไฟล์ด้วยมือ: สร้างคิวตาม scope → ดาวน์โหลด HTML รายการคิวแล้วเปิดเอง → ระบุโฟลเดอร์
Downloads เฉพาะงานนี้ → เริ่มเฝ้าดาวน์โหลดก่อน export ทีละบริษัทตามลำดับ → หยุดตัวเฝ้า → นำเข้างบ
หรืออัปโหลด XLSX/HTML ที่มีเลขทะเบียน 13 หลักในชื่อ แล้วกดนำเข้างบตาม scope
การจับคู่ดาวน์โหลดอาศัยลำดับคิว ไม่สามารถยืนยันบริษัทจากเนื้อหาไฟล์ให้ได้

ไฟล์ที่อัปโหลดชื่อเดิมจะแทนที่ไฟล์นั้นในโฟลเดอร์ของแอป ไฟล์ละไม่เกิน 24 MB
หากคอลัมน์ CSV ไม่ตรง alias ที่ระบบรู้จัก ให้แก้ `config\scope.yaml` ในโฟลเดอร์ข้อมูลของผู้ใช้
ส่วน `registry.columns`/`registry.encoding` แล้วเปิดแอปใหม่ ดูตัวอย่างในเอกสารโปรเจกต์

Chromium ยังใช้ robots.txt, rate limit และ allowed_hosts เดิม ไม่มีการเพิ่มโฮสต์อัตโนมัติ
ถ้าเข้าแหล่งข้อมูลไม่ได้ แอปจะแสดงข้อผิดพลาดและยังใช้เส้นทางนำเข้าไฟล์ได้
ผลทดสอบตัวแอปใช้บริษัทสมมติ ไม่ใช่การรับรองว่าเข้า DBD จริงได้

## สำหรับคน build และดูแล

บน Windows ที่มี Python 3.10+ (CI ใช้ 3.12):

```powershell
pip install -e ".[desktop]"
python scripts/build_windows_app.py
```

ได้ `dist\thfin-windows.zip` สคริปต์ build รวม Chromium และรัน `thfin.exe --self-test`
กับเว็บ/ไฟล์สมมติบน loopback ก่อนสร้าง ZIP ไม่อ่านข้อมูลใน workspace ผู้ใช้
Windows ที่ไม่ได้เซ็นโค้ดอาจแสดง SmartScreen; ตรวจแหล่งดาวน์โหลดกับทีมก่อนเปิด

ระหว่างพัฒนาใช้ `thfin app` หรือ `thfin app --workspace C:\path\to\workspace`
ถ้ามี Python ในระบบอยู่แล้ว ส่วน `thfin ui` เดิมยังเป็นหน้าสร้าง scope แบบ offline
